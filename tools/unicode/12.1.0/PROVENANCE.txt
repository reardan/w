These files are byte-for-byte the Unicode 12.1.0 release files (emoji data 12.0,
which Unicode 12.1 uses). Canonical sources:
  https://www.unicode.org/Public/12.1.0/ucd/<file>  (extracted/ for
  DerivedGeneralCategory.txt and DerivedBinaryProperties.txt)
  https://www.unicode.org/Public/emoji/12.1/emoji-data.txt
They were fetched on 2026-11-08 from the Unicode Consortium's own mirror,
https://github.com/unicode-org/unicodetools (branch main), paths
unicodetools/data/ucd/12.1.0-Update/<file> and
unicodetools/data/emoji/12.1/emoji-data.txt, because www.unicode.org was not
reachable from the build container. DerivedCoreProperties.txt matches the
SHA-256 that libs/extras/javascript/unicode_12_1.ranges recorded from
www.unicode.org; each file's header names its 12.1.0 version and date.

tools/javascript_regexp_property.py generates
libs/extras/javascript/regexp_property.w from them (--check: staleness,
--verify: exhaustive comparison with the compiled tables).
